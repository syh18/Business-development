# Bisniz — Business Development System

Aplikasi web pendamping untuk pemula yang ingin mulai dan mengelola bisnis kecil.

## Fitur utama
- Pilihan jenis bisnis: FnB dan Jasa
- Kalkulator HPP per unit dengan formula biaya bahan
- Kalkulator harga jual online untuk GoFood, GrabFood, dan ShopeeFood
- Input diskon, fee platform, dan biaya promo
- Pencatatan penjualan berdasarkan channel
- Dashboard revenue, order, AOV, dan produk aktif
- Grafik tren revenue dan channel mix
- Business pulse dan decision prompts
- Panduan langkah mulai bisnis
- Responsive untuk desktop dan mobile

## Teknologi
Next.js App Router, React, Recharts, Lucide React.

## Menjalankan lokal
```bash
npm install
npm run dev
```

Buka http://localhost:3000.

> Catatan: data transaksi pada prototype saat ini dikelola di state browser. Untuk production, sambungkan persistence/database dan autentikasi.
